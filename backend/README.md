# AI-Powered Disease Risk Predictor Backend

This is the FastAPI backend for the AI-Powered Disease Risk Predictor project.

## Features
- **FastAPI**: High-performance REST API.
- **Pydantic**: Robust input validation.
- **Scikit-Learn/XGBoost**: Machine learning inference using pre-trained models.
- **SHAP**: Explainable AI generating feature importance for individual predictions.

## Setup Instructions

1. **Navigate to the backend directory:**
   ```bash
   cd disease-risk-predictor/backend
   ```

2. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the API server:**
   ```bash
   uvicorn main:app --reload
   ```
   The API will be available at `http://127.0.0.1:8000`.

## API Endpoints

### `GET /health`
Returns the health status of the API and verifies if the machine learning model is loaded.

### `POST /predict`
Accepts patient health metrics and returns the disease risk level, confidence percentage, and top contributing factors based on SHAP values.

**Request Body:**
```json
{
  "Pregnancies": 6,
  "Glucose": 148,
  "BloodPressure": 72,
  "SkinThickness": 35,
  "Insulin": 0,
  "BMI": 33.6,
  "DiabetesPedigreeFunction": 0.627,
  "Age": 50
}
```

**Response Body:**
```json
{
  "risk_level": "High Risk",
  "confidence_percentage": 78.4,
  "top_factors": [
    {
      "name": "Glucose",
      "impact": 0.4085,
      "direction": "increasing"
    },
    ...
  ]
}
```
